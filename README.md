# Biomedical Image Processing — Exercises

Introductory exercises in biomedical image processing,
implemented in Python using OpenCV, NumPy, and scikit-image.

## Contents

| Week | Topic | Key Methods |
|------|-------|-------------|
| Week_01 | RGB & Grayscale | Color space conversion, channel manipulation |
| Week_02 | Contrast Enhancement | Brightness/contrast, histogram equalization, CLAHE, thresholding, histogram matching |
| Week_03 | Image Filtering | Box filter, Gaussian filter, median filter, noise removal |

## Tools & Libraries
- Python 3.10
- OpenCV (`opencv-python-headless`)
- NumPy
- scikit-image
- Matplotlib
- tifffile
